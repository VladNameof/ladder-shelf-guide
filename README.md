## O projekcie / О проекте

* **PL:** Interaktywna instrukcja 3D montażu kompaktowej, sztywnej kieszeni bocznej (`490 × 440 × 110 mm`) na lewą poręcz drabiny magazynowej/serwisowej przy szafach serwerowych **Compute Shelf**. Konstrukcja wykonana z rur modułowych **Lean Pipe Ø28 mm** (`10 odcinków`, łącznie `3,00 m`) oraz złączy z projektu Compute Shelf: **8× HJ-1** (trójnik T) i **4× HJ-2** (narożnik 3D). Zachowuje odstępy po `5 cm (50 mm)` od końców poręczy i uchwytu skanera, bezpiecznie mieści tablet serwisowy, dokumentację A4 oraz narzędzia.
* **RU:** Интерактивная 3D-инструкция по сборке компактного бокового кармана (`490 × 440 × 110 мм`) на левое ограждение лестницы для работы у стоек **Compute Shelf**. Собрана из труб **Lean Pipe Ø28 мм** (`3.00 м`), **8× HJ-1** и **4× HJ-2**, с отступами по `5 см` по краям.
