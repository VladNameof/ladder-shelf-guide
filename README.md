## O projekcie / О проекте

* **PL:** Interaktywna instrukcja 3D montażu sztywnej kieszeni roboczej (`490 × 440 × 110 mm`) z **ergonomicznym pochyleniem o 15°** w stronę podestu drabiny przy szafach serwerowych **Compute Shelf**. Kąt 15° uzyskany dzięki różnicy długości wsporników (`145 mm` góra, `30 mm` dół) i obrotowi złączy **HJ-1** na okrągłych poręczach drabiny umożliwia **błyskawiczne i naturalne wyjmowanie tabletu, podkładki A4 i narzędzi jedną ręką**, bez kolizji z poręczą drabiny. Konstrukcja wykonana z rur modułowych **Lean Pipe Ø28 mm** (`10 odcinków`, łącznie `3,00 m`) oraz złączy: **8× HJ-1** (trójnik T) i **4× HJ-2** (narożnik 3D). Zachowuje odstępy po `5 cm (50 mm)` od końców poręczy i uchwytu skanera.
* **RU:** Интерактивная 3D-инструкция по сборке компактного бокового кармана (`490 × 440 × 110 мм`) с **эргономичным наклоном 15°** на левое ограждение лестницы для работы у стоек **Compute Shelf**. Наклон 15° задается разницей длины распорок (`145 мм` верх, `30 мм` низ) на поворотных хомутах **HJ-1**, что позволяет **легко доставать планшет, документацию А4 и инструмент одной рукой по естественной траектории движения руки**, не задевая верхний поручень. Собрана из труб **Lean Pipe Ø28 мм** (`3.00 м`), **8× HJ-1** и **4× HJ-2**, с отступами по `5 см` по краям.
